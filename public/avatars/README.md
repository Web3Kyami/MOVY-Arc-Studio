# Profile assets

`alex.png` is an original AI-generated portrait of a fictional Demo user, created for this redesign. It is not a photograph of a connected wallet owner and is never assigned by default to a connected profile. The approved reference board is not cropped into production assets.

Sage, Sand and Clay are original initial avatars using MOVY's restrained neutral palette. The small library is offered for owner review in this draft PR. Uploaded and camera photos are cropped and re-encoded locally. Connected profiles are stored with the wallet address; demo profiles remain in the browser.
